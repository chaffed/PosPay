Organization Settings & Branding

Tenant-wide configuration lives at Settings.

{{ docs.screenshot("settings", "Organization settings screen") }}

What you can configure

  • Branding — display name, accent color, logo, and favicon. These appear across the whole application, including the login page for your organization.
  • Contact info — support email, phone, website, and address, shown in the footer of every page.
  • Dual control — require that the person who finalizes an exception decision be different from whoever recommended it. See Exceptions & Decisioning for how this plays out for reviewers.
  • Session timeout — how long a signed-in session stays valid before re-authentication is required.
  • Data export timeout — how long an export job is retained before it expires. See Data Export.

Dark mode

Each user can set their own display theme — System, Light, or Dark — from the control at the top of every page. There's no organization-wide setting to force one; it's always an individual preference.
